NovelVoice privacy policy

NovelVoice and NovelVoice PC are a personal, non-commercial project used by their developer.

Google user data

  • What is accessed: files in the user's own Google Drive – the NovelVoice folder (app versions and chapter files that NovelVoice PC uploads) and problem-report files the user saved from the phone.
  • How it is used: only to upload those files and download them to the user's own phone and PC.
  • Storage: the sign-in token is stored only on the user's own PC. No Google data is sent to any other server.
  • Sharing: Google user data is never sold, shared with third parties, or used for advertising.
  • Removal: access can be withdrawn at any time at myaccount.google.com/permissions.

The app itself

NovelVoice collects no analytics and has no accounts. Problem reports are created only when the user chooses to, and are saved wherever the user chooses.
